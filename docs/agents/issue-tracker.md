# Issue tracker: Obsidian (Kanban)

Задачи для этого проекта ведутся вне репозитория — в Obsidian vault, на
доске Kanban (плагин `kanban-plugin`):

`/home/opodchasov/my_vault3/projects/recipes book app/Recipes book app.md`

## Структура доски

Колонки: **Backlog** → **Todo** → **Work In Progress** → **Done**.

- Мелкая задача — просто пункт-чекбокс в колонке.
- Крупная задача — пункт-ссылка `[[Название задачи]]` на отдельную
  заметку в той же папке (`projects/recipes book app/`), созданную по
  шаблону `projects/recipes book app/templates/project task template.md`.

## Конвенции

- **Опубликовать задачу в трекер**: добавить пункт-чекбокс в колонку
  Backlog; для крупной задачи — дополнительно создать заметку по
  шаблону и сослаться на неё через `[[Название]]`.
- **Взять задачу в работу**: переместить пункт из Todo/Backlog в Work
  In Progress.
- **Закрыть задачу**: переместить пункт в Done и отметить чекбокс
  `[x]`.
- **Прочитать задачу**: открыть заметку `[[Название]]`, если она есть;
  иначе текст пункта в колонке и есть вся задача.

## Когда скилл говорит "publish to the issue tracker"

Добавить пункт в колонку Backlog (см. выше).

## Когда скилл говорит "fetch the relevant ticket"

Прочитать заметку `[[Название]]` в папке
`projects/recipes book app/`, либо соответствующий пункт на доске,
если отдельной заметки нет.
